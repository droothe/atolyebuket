# Atölye Buket

Atölye Buket; çiçek, nişan ve özel gün tasarımlarını tanıtan bir vitrin ve sipariş formu demosudur. Gelin buketi, isteme çiçeği, nişan çikolatası ve benzeri ürün grupları sergilenir. Ziyaretçiler ürün grubu seçerek sipariş talebi gönderebilir; demo yönetim panelinde örnek siparişler görüntülenebilir. Sipariş verileri tarayıcıda saklanır, gerçek bir sipariş altyapısına bağlı değildir.

## Geliştirme

Gereksinimler: [Bun](https://bun.sh/)

```sh
bun install
bun run dev
```

Üretim derlemesi için `bun run build`, testler için `bun run test` komutlarını kullanın.

İşletme, iletişim ve ürün bilgileri örnek amaçlıdır.
